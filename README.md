# Dataset: Casimir–Lifshitz Force Variations Across Heterogeneous Gapped Metal Surfaces

---

## 1. Dataset Description

This dataset contains the numerical simulation data, figure source files, and scripts used in the study of **Casimir–Lifshitz force variations across heterogeneous metallic surfaces** separated by nanoscale gaps. The dataset supports analysis of force modulation due to material inhomogeneity, gap variation, and surface patterning.

### Related Publication

**Title:** Casimir–Lifshitz Force Variations Across Heterogeneous Gapped Metal Surfaces  
**DOI:** [10.1103/PhysRevB.110.045424](https://doi.org/10.1103/PhysRevB.110.045424)
